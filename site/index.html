Planstar · 企划星

面向 Flutter 客户端的后端 API：单一 Kratos v3 服务，覆盖演出、动态、消息、订单与用户，内置 Redis、RabbitMQ、Elasticsearch、Consul、Jaeger 与 Prometheus。

GitHub 仓库 API 契约 Release

能力概览

演出与动态

演出列表 / 热门榜 / 详情，动态与评论，支持分页与城市、分类筛选。

订单与支付

下单、订单列表与详情、取消；金额元存库、分输出。

用户与认证

Cookie 会话、图形验证码、短信码限流与登录失败保护。

可观测性

Prometheus 指标、Jaeger 链路追踪、结构化日志与告警规则。
